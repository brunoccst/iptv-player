# assets

App icon images, generated by `scripts/render-icons.mjs` from one design (the web app's icons come from the same script).

| File | Used for |
|------|----------|
| `icon.png` | Launcher icon (1024 px, dark background). |
| `adaptive-icon.png` | Android adaptive icon foreground (art inside the safe zone, transparent). |
| `splash-icon.png` | Native launch screen (`expo-splash-screen`) and the first "Starting" screen in `App.tsx`. |
| `tv-banner.png` | Android TV home-screen banner (320×180). |
