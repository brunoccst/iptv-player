# player

| File                | Purpose                                                                                                                                                                                                                                                                                                                                  |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PlayerScreen.tsx`  | Source resolution (download → original file → HLS), remote handling via `RemoteSeekController` (live: ↑ guide overlay), phone touch (tap, double tap ±10 s, timeline drag, landscape lock), progress saving, Skip ahead (30 s / 1 / 2 / 3 min), next-up, overlay; the profile's subtitles and audio are selected once per title (D-087). |
| `TouchLevels.tsx`   | Phones: `usePlayerSwipes` (left third brightness, right third volume, live swipe up in the middle opens the guide) and the `LevelBar` shown while sliding and with the controls (D-046).                                                                                                                                                                       |
| `SeekOverlay.tsx`   | `TapFlash` (±10 circle animation) and `ScrubBar` (preview position + speed).                                                                                                                                                                                                                                                             |
| `externalPlayer.ts` | `openInExternalPlayer(target)`: resolves the stream and hands it to another player app (D-057).                                                                                                                                                                                                                                          |
| `GuideOverlay.tsx`  | Re-exports the guide over the playing channel, shared with the desktop (`packages/screens`, D-058, D-209). |
| `NextUp.tsx`        | Re-exports the next-episode countdown card, shared with the desktop (`packages/screens`, D-211). |
| `SkipAhead.tsx`     | Re-exports the Skip ahead button and options, shared with the desktop (`packages/screens`, D-212). |
| `PlayerHeader.tsx`  | Re-exports the player's top bar, shared with the desktop (`packages/screens`, D-213). |
| `QuickDrawer.tsx`   | Re-exports the Audio, Subtitles, Versions and Episodes panel, shared with the desktop (`packages/screens`, D-046, D-210). |
| `useExternalPlayer.ts` | The details' "open in another player" for the shared screen (D-057, D-203); none on Kids profiles. |
