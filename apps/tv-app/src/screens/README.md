# screens

Each screen mirrors the web page with the same name ([D-079](../../../../documentation/DECISIONS.md#d-079)).

| File                  | Screen                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LoginScreen.tsx`     | Sign-in: the screen shared with the desktop (`@iptv/screens`, D-199); the host gives it the backup restore and the code to sign in from the phone app (D-060). |
| `ProfilesScreen.tsx`  | "Who's watching?": the screen shared with the desktop (`@iptv/screens`, D-200); the host gives it the PIN prompt, Kids categories, languages and Sign out. |
| `HomeScreen.tsx`      | Home: the screen shared with the desktop (`@iptv/screens`, D-197), with the library notice floating at the bottom, over the rows. |
| `titles.tsx`          | Re-exports `TitleCard`, `TitleGrid` and `TvLines` from `@iptv/screens` (D-194, D-195). |
| `usePagedLibrary.ts`  | Page-by-page library loading for rows and grids (`loadMore`, `loadingMore`).                                                                                                                                                                                                                                                                                                                                                    |
| `BrowseScreen.tsx`    | Movies or Series: the screen shared with the desktop (`@iptv/screens`, D-195) with the TV's library banner over it. |
| `SearchScreen.tsx`    | Search: the screen shared with the desktop (`@iptv/screens`, D-196): "Results for …" with a filter, Movies and Series grids, live channels and guide programmes. Searches once typing pauses (`searchDelay.ts`). |
| `DetailsScreen.tsx` | Details: the screen shared with the desktop (`@iptv/screens`, D-202); the host gives it Download, Play on TV, another player, Split or merge and the episode menu. |
| `LiveScreen.tsx`      | Live TV: the screen shared with the desktop (`@iptv/screens`, D-201); the host gives it the remote's keys and the nav link Up goes to. |
| `MyListScreen.tsx`    | My List: saved titles as a grid, newest first (D-055). Home also shows a My List row (first 10 + arrow card).                                                                                                                                                                                                                                                                                                                   |
| `DownloadsScreen.tsx` | My Downloads: the screen shared with the desktop (`@iptv/screens`, D-198); the host turns the TV's downloads into its list. |
| `LogScreen.tsx`       | Diagnostics log preview, **Share log** (newest ~15,000 characters with repeated lines folded, because share targets cut long texts; credentials masked), **Clear log**. Opened from the account menu. [D-039](../../../../documentation/DECISIONS.md#d-039).                                                                                                                                                                    |
| `*.test.tsx`          | Search and log, guide (TV and phone), profile editor.                                                                                                                                                                                                                                                                                                                                                                           |
