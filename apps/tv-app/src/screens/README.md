# screens

Each screen mirrors the web page with the same name ([D-079](../../../../documentation/DECISIONS.md#d-079)).

| File                  | Screen                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LoginScreen.tsx`     | Web-style sign-in panel (provider address, username, password), "Restore from backup" (D-056), and on TVs a QR code to sign in from the phone app (D-060).                                                                                                                                                                                                                                                                      |
| `ProfilesScreen.tsx`  | "Who's watching?"; Manage Profiles adds, edits (name, colour, Kids) and deletes profiles. The editor also opens Choose categories (Kids) and Choose languages.                                                                                                                                                                                                                                                                  |
| `HomeScreen.tsx`      | Hero, Continue Watching, Live TV, Series and category rows. The library notice floats at the bottom, over the rows.                                                                                                                                                                                                                                                                                                             |
| `titles.tsx`          | `TitleRow` (Home rows: first 10 titles; the title and the "See all" arrow card open Movies/Series on that category, D-040), `TopRatedRow`; re-exports `TitleCard`, `TitleGrid` and `TvLines` from `@iptv/screens` (D-194, D-195). |
| `usePagedLibrary.ts`  | Page-by-page library loading for rows and grids (`loadMore`, `loadingMore`).                                                                                                                                                                                                                                                                                                                                                    |
| `BrowseScreen.tsx`    | Movies or Series: the screen shared with the desktop (`@iptv/screens`, D-195) with the TV's library banner over it. |
| `SearchScreen.tsx`    | Search: the screen shared with the desktop (`@iptv/screens`, D-196): "Results for …" with a filter, Movies and Series grids, live channels and guide programmes. Searches once typing pauses (`searchDelay.ts`). |
| `DetailsScreen.tsx`   | Web details panel over the current page: backdrop, Play/Resume, download, facts, cast, version select, episodes of all versions with a version picker per episode (D-066).; "Watched" tag on the title (movie, or every episode of a series) and on episodes, each episode row has Play, "…" and the version; "…" or hold OK opens its menu: Mark as (not) watched, Download, Play on TV, Open in another player (D-081, D-078) |
| `LiveScreen.tsx`      | Web guide: categories, Earlier / Now / Later, programme details, 3-hour channel × time grid. TV: focus describes, Select plays. Phone: tap selects, "Watch live" plays. [D-032](../../../../documentation/DECISIONS.md#d-032).                                                                                                                                                                                                  |
| `MyListScreen.tsx`    | My List: saved titles as a grid, newest first (D-055). Home also shows a My List row (first 10 + arrow card).                                                                                                                                                                                                                                                                                                                   |
| `DownloadsScreen.tsx` | My Downloads: progress bar, round Play / Pause / Resume / Delete buttons.                                                                                                                                                                                                                                                                                                                                                       |
| `LogScreen.tsx`       | Diagnostics log preview, **Share log** (newest ~15,000 characters with repeated lines folded, because share targets cut long texts; credentials masked), **Clear log**. Opened from the account menu. [D-039](../../../../documentation/DECISIONS.md#d-039).                                                                                                                                                                    |
| `*.test.tsx`          | Search and log, guide (TV and phone), profile editor.                                                                                                                                                                                                                                                                                                                                                                           |
