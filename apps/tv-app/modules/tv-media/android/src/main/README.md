# main

Part of the Android library layout for `tv-media`.

| Path | Contents |
| --- | --- |
| `AndroidManifest.xml` | Download service + permissions |
| `assets/name-parser.js` | Name parser for `NameParser.kt`, generated by `apps/tv-app/scripts/build-name-parser.mjs` (D-188) |
| `java/expo/modules/tvmedia/` | Kotlin sources |
| `res/values/strings.xml` | Notification channel name |

`res/` has no README: Android fails the build on non-resource files there (see D-002). `assets/` has none either: everything in it goes into the APK.
