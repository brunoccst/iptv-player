# public

Static files served at the site root. Icons are generated by `scripts/render-icons.mjs` (same design as the APK).

| File | Used for |
|------|----------|
| `favicon.svg` | Browser tab icon. |
| `icon-192.png`, `icon-512.png` | PNG icons (browsers without SVG favicons, home screen). |
| `apple-touch-icon.png` | iOS "Add to Home Screen". |
