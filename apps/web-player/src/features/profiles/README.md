# profiles

| File                   | Purpose                                                                                                                                                                                                                                                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ProfilePicker.tsx`    | "Who's watching?": the screen shared with the TV app (`@iptv/screens`, D-200); `../browse/screenHost.tsx` gives it the PIN prompt, Kids categories, languages and sign-out. |

| `PinSettings.tsx`      | Account menu → Parental PIN: set (optional), change or remove.                                                                                                                                                                                                                                              |
| `avatar.ts`            | Avatar colour palette; `avatarKey` stores the chosen colour.                                                                                                                                                                                                                                                |
