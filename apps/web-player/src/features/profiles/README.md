# profiles

| File                   | Purpose                                                                                                                                                                                                                                                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ProfilePicker.tsx`    | "Who's watching?": the screen shared with the TV app (`@iptv/screens`, D-200); `../browse/screenHost.tsx` gives it the PIN prompt, Kids categories, languages and sign-out. |
| `PinDialog.tsx`        | Parental PIN prompt (`PinDialog`, `PinInput`) and `usePinGate`, which runs an action directly or after the PIN (D-054).                                                                                                                                                                                     |
| `KidsCategories.tsx`   | Profile editor → Choose categories: what a Kids profile may see per section (D-053).                                                                                                                                                                                                                        |
| `LanguageSettings.tsx` | Account menu → Profiles → Content language filter: only titles with audio or subtitles in one of the chosen languages (from the title's name, else its category's name; titles in a category without a language always show), per profile (D-063). Also opened from the profile editor for a given profile. |
| `PinSettings.tsx`      | Account menu → Parental PIN: set (optional), change or remove.                                                                                                                                                                                                                                              |
| `avatar.ts`            | Avatar colour palette; `avatarKey` stores the chosen colour.                                                                                                                                                                                                                                                |
