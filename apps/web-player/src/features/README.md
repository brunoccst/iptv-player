# features

| Folder | Screen / feature |
|--------|------------------|
| `auth/` | Login form. |
| `profiles/` | "Who's watching?" picker and profile editor. |
| `shell/` | Signed-in layout, top navigation, library status banner. |
| `home/` | Hero (backdrop + trailer), Continue Watching, Live and category rows. |
| `browse/` | Movies/Series grids with category chips; search results. |
| `live/` | Live TV channel list by category. |
| `details/` | Details modal: versions, play/resume, download, episodes. |
| `player/` | Player overlay, engine, timeline previews, menus, next-up. |
| `downloads/` | My Downloads page. |
